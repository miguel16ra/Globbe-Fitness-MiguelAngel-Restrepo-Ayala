## Presentación profesional del proyecto
El proyectoe es una app de gestión para gimnasio, pensada para centralizar información sobre socios, clases, reservas y productos en un entorno de escritorio conectado a una base de datos.
El proyecto intenta resolver una necesidad real de organización interna: registrar información, consultar datos y relacionar distintas entidades del negocio en una aplicación usable.
El proyecto utiliza tecnologías como Java, JDBC, SQL y MySQL, además de trabajo con XML/XSD para representar y validar datos estructurados del sistema.
Desarrollando este proyecto he aprendido a conectar bases de datos con el IDE y a utilizar JavaFX, además de a organizar mejor las carpetas.

# XML y XSD - Globbe Fitness

Este XML representa una exportación de reservas de clases, incluyendo información de la reserva, del socio y de la clase.

## Archivos
- `reservas.xml`: datos exportados del sistema.
- `reservas.xsd`: esquema de validación.
- `reservas_invalido.xml`: ejemplo opcional con errores para demostrar la validación.

## Validación
El archivo `reservas.xml` se valida contra `reservas.xsd` mediante el validador XML del IDE.

## Integración con el proyecto
Este XML representa información real de la base de datos de reservas de la app.

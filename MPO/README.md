# MPO - Ampliación de Programación

## Explicación de la arquitectura del proyecto
Globbe Fitness Center está organizado en varias partes para separar mejor el trabajo. La interfaz muestra la información, la lógica de negocio hace las operaciones y la parte de datos se encarga de la conexión con la base de datos. Esto hace que el proyecto sea más claro y fácil de mantener.

## Qué parte corresponde al MPO
La mejora MPO consiste en haber organizado mejor el proyecto y separar las responsabilidades en distintas clases. Así el código queda más limpio, más fácil de leer y más fácil de ampliar.

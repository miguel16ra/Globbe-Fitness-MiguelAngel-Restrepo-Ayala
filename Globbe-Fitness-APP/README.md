# Globbe Fitness Center

Aplicación de escritorio desarrollada en JavaFX para la gestión de un gimnasio. Permite administrar usuarios, socios, productos, clases y reservas mediante JavaFX conectada a base de datos.

## Qué hace la aplicación

La App está pensada para la gestión de una base de datos de un gimnasio de mi pueblo, desde la aplicación se pueden realizar operaciones de CRUD relacionadas con el gimnasio, gracias a conectar JavaFX a una base de datos con JDBC.

## Cómo se ejecuta

Para ejecutar la aplicación es necesario tener instalado Java, Maven y disponer de la base de datos configurada correctamente, dándole al botón de ejecutar en Java

## Qué funcionalidades tiene

La aplicación incluye las siguientes funcionalidades:

- Gestión de usuarios.
- Gestión de socios.
- Gestión de productos.
- Gestión de clases.
- Gestión de reservas.
- Altas de registros.
- Consulta de datos en tablas.
- Modificación de registros existentes.
- Eliminación de registros.
- Búsqueda y filtrado de información.
- Limpieza de formularios.
- Navegación entre vistas de administración.

## Qué parte usa la base de datos

En esta aplicacion se usa en la parte del CRUD, es decir, en insertar, consultar, actualizar o eliminar..

Cada vez que se inserta, consulta, actualiza o elimina información, la aplicación accede a la base de datos mediante JDBC y clases DAO.

## Tecnologías utilizadas

- Java
- JavaFX
- JDBC
- Maven
- FXML
- Lombok
- MySQL / MariaDB
